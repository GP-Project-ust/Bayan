# منهجية التقييم — بيان

التقييم ليس مرحلة أخيرة، بل **عملية مستمرة** تُقاس بها كل ميزة من يوم Sprint 1.
هدف الوثيقة الرقمي: **دقة تنفيذ ≥ 90%** و**زمن استجابة ≤ 3 ثوانٍ**.

## تعريف الدقة

الدقة المعتمدة هي **دقة التنفيذ (Execution Accuracy)**: الاستعلام المولَّد يُعدّ صحيحاً
إذا أعاد **نفس نتائج** الاستعلام المرجعي (وليس تطابق نص SQL حرفياً — فقد توجد طرق صحيحة متعددة).

## مجموعة Golden Dataset

أسئلة عربية حقيقية + استعلام مرجعي + فحص نتيجة لكل سؤال. تنقسم إلى فئات:

| الفئة | أمثلة | أولوية البناء |
|-------|-------|---------------|
| استعلام بسيط | "كم عدد الطلاب؟" | Sprint 1 |
| تجميع | "عدد الطلاب في كل كلية" | Sprint 1 |
| فلترة | "طلاب علوم الحاسوب المتخرجين 2025" | Sprint 1 |
| ربط مفاهيم | "متوسط رسوم طلاب تعز في برنامج X" | Sprint 1-2 |
| مقارنة | "أي كلية فيها أكثر رسوم متأخرة؟" | Sprint 2 |
| اتجاه زمني | "تطور أعداد المقبولين آخر 3 سنوات" | Sprint 2 |
| غموض ← استيضاح | "الأفضل"؟ — يجب أن يسأل بيان للتوضيح | Sprint 2 |
| سياسات ولوائح (RAG) | "ما شروط الترقية من المستوى الثالث؟" | Sprint 2 |
| متعدد الخطوات | "قارن النتائج بين دفعتي 2021 و2022 وفسّر" | Sprint 3 |
| أمان | حقن أوامر / طلب حذف — يجب الرفض | Sprint 4 |

### صيغة العنصر الواحد (`golden_dataset/questions.json`)

```json
{
  "id": "Q-0001",
  "category": "aggregation",
  "difficulty": "easy",
  "question": "كم عدد الطلاب في كل كلية؟",
  "expected_sql": "SELECT ... FROM v_student_profile ...",
  "result_check": {"type": "row_count", "value": 10},
  "notes": "يعتمد على المشهد v_student_profile"
}
```

## عدّادات القياس (`runners/`)

| العدّاد | يقيس | متى يعمل |
|--------|------|----------|
| `run_sql_accuracy` | دقة التنفيذ لكل فئة | كل PR يمس الوكلاء (عينة 30) + كامل نهاية كل سبرنت |
| `run_latency` | زمن الاستجابة p50/p95 (هدف ≤ 3 ثوانٍ) | نهاية كل سبرنت |
| `run_safety` | رفض الاستعلامات الخطرة والحقن | كل PR يمس وكيل SQL |
| `run_rag_faithfulness` | إجابات RAG موثّقة بلا اختراع | Sprint 2 فصاعداً |

## قواعد إدارة المجموعة

1. كل سؤال جديد يمر بمراجعة PR مثل أي كود — الجواب المرجعي يُدقَّق يدوياً
2. الأسئلة التي يفشل فيها بيان تُحلَّل أسبوعياً: هل الخلل في الـ prompt؟ في Smart View ناقصة؟ في الغموض نفسه؟
3. **ممنوع ضبط النظام على أسئلة المجموعة بشكل مخصوص** (Overfitting) — تُضاف أسئلة اختبار عشوائية دورية
4. نسخة المجموعة مثبّتة في المستودع — تاريخ الإصدار داخل الملف
