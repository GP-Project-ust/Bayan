## المكونات ومسؤولياتها

| المكون | التقنية | المسؤولية |
|--------|---------|-----------|
| واجهة المحادثة | Next.js 15 + React 19 + Tailwind | محادثة عربية RTL، جداول ورسوم، لوحة تحكم |
| البوابة الخلفية | FastAPI + SQLAlchemy | REST، مصادقة، تطبيع، تدقيق، حدود |
| مخطط الوكلاء | LangGraph | التنسيق بين الوكلاء الخمسة والحالة |
| وكيل SQL | LLM + sqlglot + Smart Views | سؤال عربي → SQL آمن → نتائج |
| وكيل RAG | Qdrant + تضمينات | استرجاع اللوائح والسياسات |
| بيئة الاختبار | Odoo 17 + OpenEduCat | بيانات جامعية واقعية للقراءة |
| قاعدة المنصة | PostgreSQL 16 + pgvector | محادثات، ذاكرة متجهية، تدقيق |
| النموذج | Ollama — Qwen 2.5 | التفكير والتوليد — قابل للتبديل |
| التقييم | Golden Dataset + عدّادات | دقة 90% وزمن ≤ 3 ثوانٍ |

## تدفق الطلب الكامل (السؤال → الإجابة)

1. **استقبال**: الطلب يدخل `POST /api/v1/chat` (تطبيع عربي موحِّد: الهمزات، التاء المربوطة، الألف المقصورة)
2. **حفظ**: المحادثة تُسجَّل في قاعدة المنصة (للذاكرة والتدقيق)
3. **توجيه**: الـ Supervisor يقرر المسار — بيانات؟ لوائح؟ مركّب؟ غامض ← استيضاح
4. **تنفيذ**: وكيل SQL يولّد فوق Smart Views → تحقق AST → تنفيذ قراءة فقط بمهلة وحد صفوف → إصلاح ذاتي حتى 3 محاولات
5. **إثراء**: المحلل يضيف الاتجاهات ونوع الرسم الأنسب، وRAG يوثّق من اللوائح عند الحاجة
6. **تجميع**: المُعِدّ يصوغ الإجابة النهائية عربياً: نص + جدول + رسم + مصادر
7. **استجابة**: ≤ 3 ثوانٍ من الاستلام إلى الرد، مع أثر الوكلاء للواجهة والقياس

## القرارات المعمارية الملزمة

1. **النموذج محلي أولاً** (Ollama/Qwen) — التبديل لمزوّد سحابي مسموح للقياس فقط، والإنتاج يعمل دون إنترنت
2. **لا وصول مباشر لجداول Odoo الخام** — وكيل SQL يرى Smart Views فقط (مصدر الحقيقة: `docs/03_smart_views.md`)
3. **قاعدة الجامعة للقراءة فقط** — على مستوى المستخدم والمعاملة والمراجعة (AST) — ثلاث طبقات دفاع
4. **كل شيء يُقاس** — أي ميزة في الوكلاء تقترن بعناصر Golden Dataset تثبت أثرها
5. **واجهة برمجية موثقة** — OpenAPI تلقائي من FastAPI: `/docs` هي المرجع الملزم للفرونت

## الأهداف غير الوظيفية (من الوثيقة)

| الهدف | القيمة | طريقة القياس |
|-------|--------|--------------|
| دقة التنفيذ | ≥ 90% | عدّاد الدقة على Golden Dataset الكاملة |
| زمن الاستجابة | ≤ 3 ثوانٍ | p95 من عدّاد الزمن |
| اللغة | عربية فصحى + عامية يمنية شائعة | فئات Goden لكل مستوى |
| الأمان | رفض كل الكتابات + كشف الحقن | عدّاد الأمان |
