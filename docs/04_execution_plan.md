# خطة تنفيذ مشروع بيان

> مشتقة من خطة Gantt في وثيقة التخرج، محدَّثة بقرارات الفريق الحالية
> (توزيع الأدوار الخمسة + جاهزية بيئة الاختبار). المرجع النهائي عند التعارض: الوثيقة.

## الفريق والمسؤوليات

| العضو | الدور | نطاق الملكية في المستودع |
|-------|-------|--------------------------|
| أحمد المتوكل | قائد + AI Lead | `backend/app/agents/` + الـ prompts + مراجعة كل PR |
| محمد الشريف | Frontend Lead | `frontend/` كاملاً |
| عبدالكريم العبدلي | Backend Lead | `backend/app/api|db|core/` + الأمان |
| وليد العنسي | Data & DevOps | `database/` + `docker-compose` + CI + بيئة Odoo |
| محمد نجيب العواضي | Evaluation & QA | `evaluation/` + التقارير الأسبوعية |

الملكية تعني المسؤولية عن الجودة، وليست حكراً على التعديل — كل تعديل عبر PR.
