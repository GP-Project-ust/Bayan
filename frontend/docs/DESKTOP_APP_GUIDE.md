# دليل تشغيل وتطوير تطبيق سطح المكتب لمنصة بيان (Bayan Desktop)

تم بناء وتكوين تطبيق سطح المكتب لمنصة **بيان (Bayan)** كبيئة تطوير حية ومحلية متكاملة (Local Live-Development Desktop Application) لنظام التشغيل Windows، ترتبط مباشرة وبشكل حي بكود المصدر الفعلي داخل بيئة العمل، دون نسخ الكود، ودون الحاجة لتصدير صفحات ثابتة (Static HTML Export)، ودون حزم إصدارات إنتاجية مجمدة (Frozen Builds).

---

## 1. الهيكلية التقنية (Architecture Overview)

يعتمد التطبيق على النموذج الهجين المدار محلياً:

```
+-------------------------------------------------------------------------+
|                  بيئة تطوير منصة بيان (Antigravity Workspace)             |
|                                                                         |
|  [محرر الأكواد / Antigravity]  <=======>  [ملفات المصدر المباشرة]       |
|                                                     |                   |
|                                                     | HMR / مراقبة      |
|                                                     v                   |
|                                        [خادم Next.js المحلي dev]        |
|                                            127.0.0.1:3000               |
|                                                     ^                   |
|                                                     | IPC / HTTP        |
|                                                     v                   |
|                                         [محرك Electron الرئيسي]         |
|                                                     |                   |
|                                                     v                   |
|                                           [نافذة سطح المكتب]            |
|                                             (بيان | Bayan)              |
+-------------------------------------------------------------------------+
```

### المكونات الرئيسية:
1. **نافذة سطح مكتب مستقلة (Electron Window):** نافذة مستقلة بدقة افتراضية `1280x840` وحد أدنى `1024x700`، بأيقونة منصة بيان الرسمية ودعم كامل للغة العربية واتجاه اليمين لليسار (RTL).
2. **مدير الخادم التلقائي (`server-manager.js`):** يدير دورة حياة خادم تطوير Next.js كعملية فرعية محلية مخفية باستخدام Node.js القياسي، مع ربط إلزامي بـ `127.0.0.1`، وفحص الجاهزية والاسترداد التلقائي.
3. **شاشة البداية العربية (`splash.html`):** تظهر فور النقر على الأيقونة لتعرض مؤشر تقدم عربي متحرك أثناء بدء تهيئة الحزم.
4. **شاشة الاسترداد ومعالجة الأعطال (`error.html`):** تظهر في حال تعثر الخادم أو حدوث خطأ، وتوفر زرين: "إعادة محاولة تشغيل الخادم" و "عرض سجلات التشخيص".
5. **جسر الحماية المسبق (`preload.js`):** عزل تام للبيئة (`contextIsolation: true`, `nodeIntegration: false`) مع توفير واجهة آمنة محددة (`window.bayanDesktop`).
6. **التشغيل المباشر عبر Electron التنفيذي:** تم ربط اختصار سطح المكتب مباشرة بملف `electron.exe` التنفيذي (GUI Subsystem) مما يضمن عدم وميض أي نافذة طرفية سوداء نهائياً، مع دعم تام لمسارات ويندوز التي تحتوي على حروف عربية.

### الطريقة الأولى: من خلال اختصار سطح المكتب (موصى بها للمستخدمين)
- انقر نقراً مزدوجاً على اختصار **بيان - Bayan** الموجود على سطح المكتب (Desktop) أو في قائمة ابدأ (Start Menu).

### الطريقة الثانية: من سطر الأوامر (للمطورين)
```bash
npm run desktop
```
أو عبر ملف الدفعة المخصص:
```cmd
.\desktop\bayan-desktop.cmd
```

## 4. دورة حياة الخادم والإدارة الذكية (Server Lifecycle)

1. **التحقق من حالة المنفذ (Port Probing):**
   - يفحص مدير الخادم ما إذا كان خادم بيان قيد التشغيل بالفعل على المنفذ `3000`. إن كان يعمل، يرتبط به مباشرة لتفادي إنشاء عمليات مكررة.
   - في حال كان المنفذ مشغولاً بخدمة خارجية غير معروفة، يبحث تلقائياً عن أقرب منفذ متاح (مثل `3001`، `3002`) دون إغلاق عمليات البرامج الأخرى.
2. **الربط الآمن:**
   - يتم تقييد تشغيل خادم Next.js دائماً على المضيف المحلي `127.0.0.1` لحظر أي وصول غير مصرح به عبر الشبكة المحلية.
3. **الإغلاق النظيف الشامل (Clean Graceful Shutdown):**
   - عند إغلاق نافذة التطبيق بواسطة المستخدم، يتم استدعاء خوارزمية `taskkill /pid <PID> /T /F` على أنظمة Windows، والتي تقوم بإنهاء شجرة العمليات بالكامل (Parent & Child Node Processes) لضمان عدم بقاء أي خوادم معلقة أو استنزاف للذاكرة أو احتجاز للمنفذ 3000.
4. **سجلات التشخيص (Diagnostics Logging):**
   - يتم تدوين كافة أحداث بدء الخادم، المخرجات القياسية، وأخطاء البناء في ملف السجل الموحد:
     `desktop/logs/bayan-dev-server.log`

## 5. الأمان وسلامة البيانات

- **عزل تام لبيئة العمل (Context Isolation):** مفعل ومطبق على نافذة التطبيق الرئيسية.
- **منع تشغيل الأوامر المباشرة (Node Integration Disabled):** واجهة الويب لا تملك أي وصول مباشر لـ `fs` أو `child_process`.
- **حظر الملاحة الخارجية:** يمنع التطبيق الانتقال إلى أي نطاقات خارجية غير `127.0.0.1` أو `localhost`.
- **فتح الروابط الخارجية بأمان:** أي رابط يوجه إلى موقع خارجي يفتح تلقائياً في المتصفح الافتراضي للنظام عبر `shell.openExternal`.
