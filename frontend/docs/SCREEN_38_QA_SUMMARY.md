## اختبارات العقود المضافة

1. وجود المسار في كتالوج 42 شاشة ودوره مسؤول المنصة.
2. صحة القيم الافتراضية العربية.
3. حدود مهلة SQL من 5 إلى 120 ثانية.
4. حدود محاولات التصحيح وإعادة التنفيذ.
5. حدود الاحتفاظ وثبات سجل التدقيق.
6. التحقق من مزود النموذج ومعرّف النموذج وحدود الطلبات والتزامن.
7. حساب الفروقات بعناوين عربية.
8. إنشاء سجل تاريخ مع نسخة سابقة مستقلة.
9. استعادة التخزين المحلي الصحيح.
10. الرجوع للقيم الافتراضية عند فساد بيانات التخزين.
11. تصدير JSON دون مفاتيح أو أسرار.
12. فرض `platform.manage` في محاكاة الواجهة وعدم وجود استدعاءات شبكة.
13. استخدام المسار المخصص وتحديده في القائمة الجانبية.
14. وجود ملفات التوثيق والتدفق والتصميم المتجاوب.

## اختبارات المتصفح المضافة

- ظهور مجموعات الإعدادات.
- التحقق من مهلة SQL وفتح نافذة مراجعة التغييرات.
- حفظ نسخة محلية وظهور سجل التغييرات.
- إظهار حالة منع الوصول عند تبديل الدور إلى موظف مؤسسة.

## حدود الاختبار

- فشل `npm run lint` في هذه البيئة بسبب عدم تثبيت حزم المشروع (`next` و`react` و`lucide-react` و`@playwright/test`)؛ لذلك لم يكتمل الفحص الدلالي الكامل.
- لم يُنفّذ `npm run build` أو اختبارات Playwright؛ لا توجد `node_modules` أو حزم المتصفح في بيئة العمل.
- اختبارات العقود وفحص الصياغة لا تثبت نجاح بناء Next.js أو تطابق العرض البصري. يجب تثبيت الحزم وتشغيل `npm run lint` و`npm run build` واختبارات Playwright على جهاز التطوير.

## حدود التنفيذ

- لا توجد اتصالات Backend.
- لا تتغير إعدادات المنصة الفعلية.
- التخزين محلي للمتصفح فقط.
- لا توجد أسرار أو مفاتيح API في النموذج.
- سياسة الاحتفاظ المعروضة مقترح قابل للمراجعة وليست قرار امتثال قانوني.
