# الشاشة 38 — إعدادات المنصة (Platform Settings)

## بيانات الشاشة

- **المسار:** `/platform/settings`
- **الدور المقترح:** مسؤول المنصة (`platform_admin`)
- **المكوّن:** `components/platform-settings/PlatformSettingsScreen.tsx`
- **منطق الإعدادات والتحقق:** `lib/platform-settings/settings.ts`
- **التصميم:** `components/platform-settings/platform-settings.css`
- **الحالة:** نموذج واجهة تفاعلي؛ لا يغيّر إعدادات Backend الفعلية.

## الهدف

توفير مكان موحد لمراجعة القيم التشغيلية العامة، وسياسات الاستعلام، والاحتفاظ بسجلات التدقيق، والحدود الوصفية لمزودي النماذج. تُعرض التغييرات في مراجعة مقارنة قبل تأكيد الحفظ المحلي.

## أقسام الشاشة

### 1. الإعدادات العامة

- اللغة الافتراضية: العربية أو الإنجليزية.
- المنطقة الزمنية الافتراضية: عدن أو الرياض أو UTC أو لندن.
- لا يغيّر الاختيار لغة محتوى المؤسسات أو تفضيلات المستخدمين الحالية.

### 2. الاستعلامات

- مهلة SQL: عدد صحيح من 5 إلى 120 ثانية؛ القيمة الافتراضية 30.
- محاولات التصحيح: من 0 إلى 3؛ القيمة الافتراضية 2.
- محاولات إعادة التنفيذ: من 0 إلى 5؛ القيمة الافتراضية 2.
- يجب أن تظل إعادة المحاولة محصورة في الأعطال المؤقتة، وألا تكرر عمليات غير آمنة.

### 3. التدقيق والاحتفاظ

- مدة الاحتفاظ: من 30 إلى 3650 يومًا؛ القيمة الافتراضية 365 يومًا.
- خيار إخفاء الحقول الحساسة مفعّل افتراضيًا.
- ثبات سجلات التدقيق قيد لا يمكن تعطيله من الواجهة؛ لا توجد أزرار لتعديل السجلات أو حذفها.
- يجب مواءمة المدة النهائية مع المتطلبات القانونية والتنظيمية وسياسة المؤسسة.

### 4. النماذج والحدود

- المزود الافتراضي: Ollama محلي، أو بوابة متوافقة مع OpenAI، أو Azure OpenAI.
- اسم النموذج الافتراضي: `qwen2.5:14b`.
- حد الطلبات: 1–600 طلب في الدقيقة؛ الافتراضي 60.
- التزامن: 1–64 طلبًا؛ الافتراضي 8.
- لا تحتوي الشاشة على حقول API keys أو كلمات مرور أو عناوين اتصال سرية.

## التفاعلات

1. تبديل مجموعات الإعدادات عبر تبويبات واضحة.
2. تعديل القيم في مسودة منفصلة عن آخر نسخة محفوظة.
3. التحقق من النطاقات والأنواع وعرض أخطاء الحقول.
4. فتح نافذة مراجعة تعرض القيمة السابقة والجديدة لكل تغيير.
5. تأكيد الحفظ؛ تحفظ النسخة في `localStorage` لهذا المتصفح فقط.
6. إنشاء سجل تغييرات محلي محدود بثمانية إدخالات، يتضمن نسخة الإعدادات السابقة لاستعادتها كمسودة.
7. إلغاء التعديلات، أو استعادة القيم الافتراضية كمسودة، أو استعادة النسخة السابقة كمسودة.
8. تصدير JSON وصفي لا يتضمن أسرارًا.

## الصلاحيات والأمان

- تستخدم الواجهة `platform.manage` من مصفوفة RBAC الحالية.
- `DemoRolePicker` يتيح اختبار حالة المنع بصريًا.
- هذا التفويض تجريبي فقط؛ يجب التحقق من الصلاحية على كل endpoint في FastAPI.
- لا يتم إجراء أي `fetch` أو اتصال شبكة أو تحديث لإعدادات الخادم.
- `localStorage` مساحة تجريبية محلية وغير موثوقة، ولا تصلح لتخزين أسرار أو سياسات إنتاج.
- لا يُعد سجل التغييرات المحلي بديلًا عن Audit Log مركزي غير قابل للتلاعب.

## التكامل المستقبلي

عند ربط Backend، يوصى بواجهات مصادق عليها مثل:

- `GET /api/v1/platform/settings` لاسترجاع الإعدادات المصرح بها.
- `PUT /api/v1/platform/settings` لتحديث الإعدادات بعد التحقق من RBAC والقيم.
- `GET /api/v1/platform/settings/history` لمراجعة تاريخ التغييرات.
- `POST /api/v1/platform/settings/validate` للتحقق المسبق دون تطبيق.

هذه مسارات مقترحة وليست مسارات منفذة حاليًا. يجب تطبيق حفظ ذري، وتسجيل الفاعل ووقت التغيير، والتحقق من النطاقات في الخادم، وحماية الأسرار في مخزن مخصص.
