# بيان — الشاشة 02: استعادة كلمة المرور (`/forgot-password`)

**التصنيف:** واجهة فعلية مستقلة ضمن فئة «الحساب» في كتالوج 42 شاشة.
**متطلب المشروع:** FR-03 في كتالوج الواجهات المخصص للفريق. **المرجع البصري:** شاشة الدخول المعتمدة وكحلي/تركوازي نظام التصميم. **الحالة:** معاينة Frontend؛ **ليست** إرسال بريد أو خدمة استعادة فعلية.

## حالات القبول

| الحالة | النتيجة المتوقعة |
|---|---|
| فتح `/forgot-password` | عرض العلامة التجارية والعنوان والحقل وزر المتابعة |
| إدخال بريد فارغ | عرض خطأ بجانب الحقل وتوجيه التركيز إليه |
| إدخال صيغة غير صحيحة | رسالة خطأ واضحة دون إرسال |
| إدخال بريد صحيح شكليًا في بيئة التطوير | حالة انتظار قصيرة ثم **تأكيد تجريبي صريح**؛ لا يرسل بريدًا |
| إعادة إدخال بريد آخر | العودة للنموذج وحذف قيمة البريد السابقة |
| الضغط على العودة | التوجه إلى `/login` |
| شاشة 390 بكسل | عدم ظهور تمرير أفقي في اختبار المتصفح |
| إيقاف المعاينة في الإنتاج | عدم إظهار نجاح زائف؛ تظهر رسالة ضرورة ربط خدمة الخادم |

### الخصوصية والأمان

1. لا يتم استدعاء `fetch` ولا أي واجهة API، ولا يتم إنشاء رموز استعادة أو نقل كلمات مرور.
2. لا يُحفظ البريد في `localStorage` أو `sessionStorage` ضمن هذه الشاشة.
3. لا يُكشف وجود بريد في قاعدة البيانات، ولا توجد عملية استعلام عنه أصلًا.
4. في الإنتاج، لا ينبغي استخدام هذه الواجهة كخدمة استعادة حتى يتم التكامل مع Backend موثوق.
5. يمكن تفعيل المعاينة صراحة في بناء الإنتاج المعزول عبر `NEXT_PUBLIC_BAYAN_DEMO_LOGIN=1`، ولا يوصى بذلك عند النشر الحقيقي.

## عقد Backend مقترح لاحقًا — غير منفذ ولا موثق في المستودع الحالي

- `POST /api/v1/auth/password-reset/request` مثال لمسار يحتاج اتفاق الفريق، وليس ادعاءً بوجوده.
- يجب أن يطبق FastAPI تحديد معدل المحاولات، ورسالة موحدة بغض النظر عن وجود الحساب، وحماية سجلات البريد من الكشف.
- يجب توليد رمز عشوائي قوي على الخادم، محدود الصلاحية وذا استخدام واحد، وتخزين تجزئته بأمان.
- يجب ألا تعبر رموز الاستعادة إلى السجلات أو تحليلات الاستخدام أو أدوات تتبع الأخطاء.
- ستحتاج شاشة مستقلة لإدخال كلمة المرور الجديدة بعد التحقق من رمز الاستعادة، ضمن دورة تطوير لاحقة.

## التشغيل والتحقق

```bash
npm install
npm run check:recovery
npm run lint
npm run build
npm run dev
# ثم افتح http://localhost:3000/forgot-password
# اختبارات المتصفح عند توافر Chromium:
npx playwright install chromium
npx playwright test tests/e2e/forgot-password.spec.ts
```

**حدود التسليم:** الاختبارات البنيوية ودالة التحقق قابلة للتشغيل دون تبعيات المشروع؛ لا يُعد ذلك شهادة بإكمال التشغيل في Next.js أو اختبار الإرسال أو الصلاحيات الأمنية.
