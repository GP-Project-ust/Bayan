# الشاشة 09 — البحث الدلالي في المستندات (Semantic Search)

**نظام بيان | Next.js + TypeScript | نسخة واجهة تدريبية**

## 1. الهدف والمرجع

تغطي هذه الشاشة مسار `UC-02` للبحث داخل المستندات واللوائح والاستشهادات، وتلتزم بالهوية البصرية المعتمدة لبيان: الكحلي `#0A2342` والتركوازي `#00A6B2` والأبيض، واتجاه `RTL`.

**تنبيه أساسي:** كل أسماء الأدلة واللوائح والمقاطع ورقم الصفحة ودرجة الصلة في هذه الشاشة عينات *مختلقة للتصميم والاختبار فقط*. لا تعكس نصوصًا حقيقية من وثائق الجامعة، ولا تنفذ الصفحة حاليًا Vector Search أو Qdrant أو RAG. درجة الصلة ناتجة عن خوارزمية مطابقة كلمات تجريبية، **وليست cosine similarity**.

## 2. مسار الشاشة

- `/semantic-search`: صفحة مستقلة تعرض البحث والتصفية والنتائج والمعاينة.
- `/screens`: كتالوج المشروع السابق، يتضمن رابط المسار.
- `/sources`: مكتبة المستندات العامة السابقة، يمكن الانتقال إليها من نتيجة البحث.
- `/`: واجهة المحادثة الرئيسية المعتمدة دون أي تعديل.

## 3. الواجهة والمكونات

| المنطقة | العناصر والتفاعل |
|---|---|
| الترويسة | العنوان والوصف وعلامة بيانات تجريبية |
| شريط البحث | إدخال عربي، زر بحث، تحقق من الفراغ والحد الأدنى والطول المفرط |
| الاقتراحات | الغياب والحرمان، التسجيل الأكاديمي، التظلم، كشف الدرجات |
| المرشحات | تصنيف المستند، عنوان المستند، مجال الصلة، ترتيب النتائج |
| النتائج | مقتطف، عنوان المستند، عنوان القسم، الصفحة، درجة توضيحية |
| معاينة المصدر | `Drawer` يعرض مقتطفًا تدريبيا مع تحذير من عدم وجود PDF حقيقي |
| نسخ الاستشهاد | نص واضح يتضمن عبارة «مثال تدريبي غير موثّق» |
| الحالات | الانتظار، رفض الوصول، المدخل غير الصحيح، عدم وجود نتائج |
| صلاحيات المعاينة | `documents.search` و`citations.view` وفق الدور التجريبي |

## 4. بيانات المحاكاة وخوارزمية البحث

توجد 12 عينة مقطع افتراضي في `lib/semantic-search/search.ts` موزعة على اللوائح، والأدلة، والسياسات، والنماذج. يطبّق البحث المحلي:

1. إزالة تشكيل العربية وتطبيع بعض أحرفها وعلامات الترقيم لاكتشاف كلمات شائعة.
2. مطابقة مفردات الإدخال مع عنوان المستند والقسم والمقتطف والكلمات الدلالية التدريبية.
3. حساب ترتيب تقريبي من التداخل اللفظي ودرجة العرض الثابتة؛ الرقم **ليس تشابهًا دلاليًا**.
4. التصفية بحسب الفئة أو المستند أو نطاق الدرجة ثم الترتيب.
5. إذا لم تتطابق أي عينة، تظهر حالة فارغة مع إمكانية إعادة تعيين الفلاتر.

لا توجد استدعاءات شبكة أو تخزين محلي للبحث في هذه الصفحة. لا تُستخدم مستندات المستخدم أو استعلامات SQL أو أرقام مؤسسات حقيقية.

## 5. صلاحيات الواجهة مقابل أمان الخادم

يختار المستخدم دورًا تجريبيًا داخل صفحة المعاينة. يستطيع `employee` و`manager` و`it_admin` اختبار البحث، بينما `platform_admin` لا يرث صلاحية الاطلاع على مستندات المؤسسة تلقائيًا. `DemoRolePicker` **عرض تجريبي فقط**، ويجب عدم إرساله للـBackend كدليل على امتلاك الصلاحية.

عند الربط الحقيقي يجب على FastAPI:

- توثيق الجلسة والتحقق من هوية المستخدم والمستأجر/المؤسسة.
- فرض صلاحية البحث وتصنيف الوثائق قبل البحث وقبل إعادة المقاطع والاستشهادات إلى المتصفح.
- تقييد البحث الدلالي في Qdrant بالفهرس والنطاق المصرح بهما وعدم السماح بتسرب مستندات مؤسسات أخرى.
- إرجاع اسم المستند الصحيح ومعرّفه ورقم الصفحة/المقطع الحقيقي، مع رابط عرض موقّع أو آمن إن سُمح به.
- توحيد استجابات الأخطاء `400/401/403/429/500` وعدم كشف بيانات حساسة في رسائل الأخطاء.
- تسجيل الوصول والتحقق من سياسات الاحتفاظ والتدقيق.

## 6. عقد API المقترح — غير منفّذ

| Method | Path مقترح | الهدف |
|---|---|---|
| `POST` | `/api/v1/documents/search` | بحث دلالي في نصوص مصرح بها؛ `query`, `filters`, `top_k` |
| `GET` | `/api/v1/documents/{id}/preview?page={page}` | معاينة صفحة موثقة مع تحقق من إذن المستند |
| `GET` | `/api/v1/documents/categories` | الفئات المرئية للمستخدم ضمن مؤسسته |

هذه **مقترحات للتصميم** وليست إثباتًا لتوفر مسارات في الخادم. يتوجب مواءمتها مع Backend مشروع بيان الفعلي.

## 7. معايير القبول

- [ ] عرض التصميم واتجاه RTL واسم الصفحة دون خلل.
- [ ] التحقق من العبارة الفارغة أو التي تقل عن 3 أحرف أو تتجاوز 180 حرفًا.
- [ ] البحث التجريبي عن «الغياب والحرمان» وإظهار المقاطع وتحديد المستند والصفحة.
- [ ] دعم فلاتر التصنيف والمستند ونطاق الدرجة والترتيب وإعادة الضبط.
- [ ] عرض حالة فارغة عند عدم وجود عينات مطابقة.
- [ ] فتح معاينة مصدر وإغلاقها بلوحة المفاتيح أو زر الإغلاق.
- [ ] منع عرض النتائج عند اختيار دور غير مصرح له في المحاكاة.
- [ ] عرض تنبيه صريح بأن البيانات وهمية وغير متصلة بخدمة RAG.
- [ ] اختبار أحجام 390px و768px و1280px والملاحة بلوحة المفاتيح.
- [ ] اختبار أخطاء الشبكة و401/403/429 عند الربط الحقيقي.

تبدأ هذه الحالات بوضع **غير مختبَر في تشغيل Next.js الفعلي**، رغم وجود اختبارات بنيوية وبرمجية وعقود.
