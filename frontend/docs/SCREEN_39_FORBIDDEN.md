# الشاشة 39 — غير مصرح بالوصول (Forbidden)

## بيانات الشاشة
- المسار: `/forbidden`
- الترتيب: 39 من كتالوج 42 شاشة.
- المكوّن: `components/forbidden/ForbiddenScreen.tsx`
- التنسيق: `components/forbidden/forbidden.css`
- الحالة: واجهة توضيحية مستقلة لحالة HTTP 403.

## الهدف
إبلاغ المستخدم بأن الحساب الحالي لا يمتلك الصلاحيات المطلوبة، مع عدم إظهار محتوى المورد المحمي أو بياناته.

## عناصر الواجهة
1. هوية بيان ورمز بوابة الوصول الآمن.
2. رمز الحالة `403 Forbidden`.
3. شرح عربي مختصر لسبب رفض الوصول.
4. لوحة حالة موحدة من `StatePanel` بالحالة `forbidden`.
5. رمز مرجعي توضيحي `BAYAN-403` وإمكانية نسخ تفاصيل الحالة.
6. العودة للصفحة السابقة مع مسار احتياطي إلى الرئيسية.
7. رابط الصفحة الرئيسية ورابط الملف الشخصي لطلب مراجعة الدور.

## السلوك والتكامل
- زر العودة يستخدم سجل المتصفح، ويعود إلى الرئيسية إذا لم يتوفر سجل سابق.
- نسخ التفاصيل يستخدم Clipboard API عند توفر إذن المتصفح.
- لا يجري المكوّن أي اتصال شبكي ولا يغيّر صلاحيات المستخدم.
- هذه الشاشة لا تستبدل التحقق الحقيقي من RBAC على الخادم. يجب أن تفرض FastAPI/API Gateway التفويض على كل endpoint، وأن تحول حالات 403 إلى هذا المسار دون تضمين بيانات حساسة في الاستجابة.
