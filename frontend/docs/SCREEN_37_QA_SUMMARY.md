# تقرير جودة الشاشة 37 — مراقبة الوكلاء

**النسخة:** شاشة 37 من مشروع واجهات بيان.

## الاختبارات المنفذة بالفعل

- فحص الصياغة لـ210 ملفات TypeScript/TSX عبر `scripts/verify-agent-monitoring.mjs`، وفحص TypeScript مركز لوحدات بيانات الوكلاء بنجاح.
- 11 اختبار عقد جديدًا للشاشة 37 تشمل تعريف الأدوار الخمسة، واتساق تجميع المؤشرات، وطريقة حساب نسب النجاح، وحالات العينة، والبحث العربي، والتصفية، وCSV، والصلاحيات، وغياب اتصالات الشبكة.
- نجحت 296 اختبارات عقود تراكمية للمشروع كاملًا دون إخفاقات.
- اختبارات العقود التراكمية لجميع الشاشات السابقة.
- فحص بصمات الملفات المرجعية للهوية البصرية والواجهات المعتمدة.
- الحفاظ على كتالوج الشاشات البالغ 42 مسارًا، مع تفعيل المسار المخصص `/platform/agents` بدل صفحة FeaturePage العامة.
- إنشاء مخطط التدفق بصيغ PNG وSVG وDOT وMermaid.

## اختبارات غير منفذة

- بناء Next.js الفعلي `npm run build` يحتاج تثبيت تبعيات المشروع أولًا.
- اختبارات Playwright أُضيفت ولم تُشغّل داخل المتصفح في بيئة التسليم.
- لا تتوفر لقطة متصفح فعلية للتحقق البصري النهائي أو اختبار تجاوب الأجهزة.

## حدود المنجز

المؤشرات مشتقة من ثمانية سجلات تتبع اصطناعية موجودة في المشروع، وليست بيانات أداء حقيقية. لا يوجد اتصال بـLangGraph أو FastAPI أو مزود نموذج، ولا توجد مراقبة إنتاجية. تفاصيل تتبعات المؤسسات لا تُعرض لمسؤول المنصة ما لم تتوفر صلاحية `traces.view`.
