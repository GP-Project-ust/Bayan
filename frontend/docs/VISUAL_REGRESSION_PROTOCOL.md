# بروتوكول المطابقة البصرية مع التصميمين المعتمدين

الصور المرجعية المعتمدة:

- `design-references/chat-reference.png` — واجهة المحادثة.
- `design-references/admin-reference.png` — لوحة الإدارة.

## شروط المقارنة

1. استخدم نافذة متصفح ثابتة **1448×1086** ومقياس Zoom 100% وDPR=1 إن أمكن.
2. ضَع المحتوى على البيانات التجريبية الافتراضية نفسها، ولا تقارن حالات استخدام مختلفة.
3. انتظر تحميل الخطوط والأيقونات والصور قبل تصوير الشاشة. خط Cairo **مقترح**؛ عند غيابه قد يتغير العرض.
4. التقط لقطات حديثة للشاشتين `/` و`/admin`، ثم قارنها بصور المرجع جنبًا إلى جنب.
5. راجع: عرض القائمة الجانبية، شريط العنوان، مساحة المحتوى، مواقع البطاقات والجداول، النصوص العربية، التباعد، الألوان، الظلال، مكان المبنى الجامعي، والأيقونات.
6. دوّن كل اختلاف: مقصود/غير مقصود، شدته، وصورة التوضيح.
7. تُراجع التعديلات المرئية قبل دمج PR؛ أي تغيير في ملفات المرجع يحتاج اعتمادًا صريحًا من مالك التصميم.

## عدم الادعاء بالمطابقة البكسلية

صور المرجع الأصلية رسومات UI، وليست snapshots مولدة من متصفح. لذلك اختلاف Rasterization والخطوط قد يجعل pixel-diff مضللًا. يُستخدم التقريب البصري والتقييم البشري معيارًا أوليًا، ويمكن بناء Snapshots لاحقًا من متصفح مضبوط بعد اعتماد النسخة الأولى بالفعل. لا يوجد الآن اختبار Pixel-perfect ناجح أو معتمد.

## لقطات المتصفح الاختيارية

```bash
npm install
npx playwright install chromium
npm run dev
# افتح localhost:3000 عند عرض 1448×1086 وسجّل الصور يدويًا
```

## ضمان عدم تغيير المرجع

يقارن `npm run check:stage7` SHA256 بين نسختي الصور في `design-references/` و`public/design-references/`، ويتحقق من ثبات ألوان الهوية الرئيسية. هذا **ليس** مقارنة شاشة الكود مع الصورة.
