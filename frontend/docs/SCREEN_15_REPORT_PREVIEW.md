# الشاشة الخامسة عشرة — معاينة التقرير وتصديره | Bayan

**المسار:** `/reports/detail?report=rep-101` (القيمة الافتراضية: `rep-101`).  
**التقنية:** Next.js App Router، TypeScript، مكونات بيان الموحدة، CSS معزول، العربية وRTL.  
**الحالة:** واجهة أمامية تفاعلية ببيانات **تجريبية غير رسمية**، لا تتصل بـFastAPI أو SQL أو Qdrant.

## الهدف

إكمال التدفق المرئي لحالة الاستخدام UC-03 عبر ثلاث شاشات متصلة:

1. مركز التقارير: `/reports` — اختيار تقرير من بيانات العينة.
2. إنشاء تقرير جديد: `/reports/new` — محاكاة إعداد التكوين فقط، **دون** إنشاء تقرير.
3. معاينة التقرير وتصديره: `/reports/detail?report=rep-101` — معاينة تقرير تدريبي موجود مسبقًا؛ **ليس** ناتج معالج التقرير.

## عناصر الشاشة

| العنصر | السلوك |
|---|---|
| اختيار التقرير | قائمة التقارير التجريبية الموجودة من الشاشة 13 مع رابط قابل للمشاركة يحوي المعرّف |
| صفحة 1 A4 | عنوان التقرير، الجهة والفترة، مؤشرات، مخطط أعمدة، مصدر البيانات وتحذير واضح |
| صفحة 2 A4 | جدول البيانات التفصيلية، بيانات المصدر، الملاحظات والتحذير |
| أزرار الصفحات | عرض الكل أو الملخص أو الجدول؛ عند الطباعة تظهر الصفحتان دائمًا |
| التكبير | خمس مستويات بين 75% و125% داخل المعاينة؛ الطباعة في الحجم الطبيعي |
| CSV | تنزيل ملف UTF-8 مع BOM، مع حماية قيم CSV التي تبدأ بعلامات الصيغ |
| Excel XLSX | إنشاء مصنف OOXML حقيقي، ورقة عربية باتجاه RTL، يحوي بيانات المثال وتنبيهًا واضحًا |
| PDF | زر يفتح نافذة الطباعة؛ يختار المستخدم **«حفظ كملف PDF»** ويصدر المتصفح ورقتين بحجم A4 عموديًا |
| جاهزية التقرير | يمنع التصدير إن كان التقرير في الانتظار أو مسودة أو تعذّر إنشاؤه |
| الصلاحيات | مدير المؤسسة يستطيع التصدير في المحاكاة؛ موظف المؤسسة يستطيع العرض دون التصدير؛ مسؤول المنصة ممنوع من رؤية التقرير في المحاكاة |
| الحالات | معرّف تقرير غير صحيح، تقرير غير جاهز، منع الوصول، رسالة تأكيد بعد تجهيز الملفات |

**تعريف التصدير بوضوح:** CSV وXLSX ينشآن محليًا باستخدام Browser Blob API من بيانات تجريبية. زر PDF لا يولد PDF مباشرة؛ هو يفتح طباعة المتصفح بصيغة A4، ويمكن حفظ PDF من مربع الحوار. لا يُنتج أي ملف حقيقي من قواعد المؤسسة.

## قواعد الأمان والدقة

- لا API calls ولا اتصال خارجي ولا تشغيل SQL.
- لا يتم حفظ محتوى التقرير في LocalStorage أو SessionStorage.
- ملفات XLSX تخزن النصوص عبر inlineStr وليس خلايا Formula، حتى عند وجود نص يبدأ بـ`=`.
- لا يتم إظهار مجموع القيم للنسب المئوية أو للوحدات المختلفة؛ لأن الجمع سيكون مضللًا.
- البيانات الموجودة ضمن `lib/reports/reports.ts` متخيلة بالكامل.
- صلاحيات الواجهة ليست حماية؛ يجب تطبيق RBAC والتحقق من المؤسسة والمصادر وحدود بيانات التقارير في FastAPI.
- لا يجوز لأي مستخدم الاعتماد على أرقام المثال كبيانات إدارية أو جامعية حقيقية.

## الربط مع الشاشات السابقة

- تمت إضافة رابط «معاينة كاملة» إلى الجدول ودرج التفاصيل في مركز التقارير، دون تغيير هيكل الشريط الجانبي المعتمد.
- عند إكمال المحاكاة في `/reports/new` يظهر رابط «معاينة مثال مستقل»، بتوضيح أن التقرير المعروض ليس تقرير المستخدم الذي أنشأه.
- يظل CSV القديم من شاشة المركز يعمل كما كان، بينما تضيف الشاشة الجديدة التصدير بصيغ أخرى.

## عقود API مستقبلية مقترحة (غير منفذة)

| Method | Endpoints مقترحة | وظيفة | الحماية المطلوبة |
|---|---|---|---|
| `GET` | `/api/v1/reports/{id}` | تقرير موثوق مع الأرقام والمصدر | `reports.view`، هوية المؤسسة، قيود المصادر |
| `GET` | `/api/v1/reports/{id}/status` | حالة إنشاء التقرير | `reports.view` وربط المؤسسة |
| `POST` | `/api/v1/reports/{id}/export` | طلب نسخة PDF/XLSX/CSV من الخادم | `reports.export`، تدقيق الطلب، تحقق المؤسسة |
| `GET` | `/api/v1/reports/{id}/export/{fileId}` | الحصول على ملف مصرح به | صلاحية قصيرة الأجل، تدقيق، حظر وصول عابر للمؤسسات |

المسارات السابقة اقتراح تصميمي، وليست مسارات منفذة في Backend حاليًا.

## كيفية التشغيل

```bash
npm install
npm run check:report-preview
npm run lint
npm run build
npm run dev
```

افتح `/reports/detail?report=rep-101` أو انتقل إليها من `/reports`.

### تجارب مبدئية

- `/reports/detail?report=rep-101` — بيانات جاهزة مع رسم وجدول وتصدير.
- `/reports/detail?report=rep-102` — نسب مئوية لا تظهر كمجموع حسابي.
- `/reports/detail?report=rep-103` — تقرير غير جاهز، لا يمكن تصديره.
- `/reports/detail?report=rep-999` — تقرير غير موجود.

### الاختبارات

`node --test tests/contracts/report-preview.test.mjs` يتأكد من اختيار التقارير، سلامة مصنف OOXML والتعامل مع المدخلات النصية، وصلاحيات العرض والتصدير بوصفها محاكاة، وقواعد الطباعة. اختبارات المتصفح في `tests/e2e/report-preview.spec.ts` تتطلب تثبيت Next.js وPlaywright أولًا.
