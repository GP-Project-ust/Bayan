# الشاشة 40 — الخدمة غير متاحة (Service Unavailable)

## بيانات الشاشة
- المسار: `/unavailable`
- الترتيب التطويري: الشاشة 40 من أصل 42.
- المكوّن: `components/unavailable/UnavailableScreen.tsx`
- التنسيق: `components/unavailable/unavailable.css`
- الحالة: واجهة توضيحية لحالة HTTP 503 / تعذر الاتصال.

## الهدف
إرشاد المستخدم عند تعذر الوصول المؤقت إلى خدمة بيان، وتوفير إعادة المحاولة والعودة إلى الصفحة الرئيسية، دون الادعاء بأن الخدمة عادت للعمل قبل تأكيد ذلك.

## عناصر الواجهة
1. هوية بيان وعنوان حالة الخدمات.
2. رمز HTTP 503 وشرح مبسط.
3. حالة مشتركة `offline` عبر StatePanel.
4. زر إعادة المحاولة مع حالة انتظار مرئية.
5. توضيح أن استعادة الاتصال لم تتأكد بعد.
6. رقم مرجعي `BAYAN-503` ونسخ تفاصيل المشكلة.
7. رابط الصفحة الرئيسية.

## السلوك والتكامل
- إعادة المحاولة تستدعي `router.refresh()` لتحديث المسار الحالي.
- الواجهة لا تختبر جميع الخدمات الخلفية ولا تستنتج سبب الانقطاع.
- لا تُظهر بيانات داخلية أو أسرار تشغيل.
- يجب أن يصدر Backend حالة HTTP 503 عند عدم توفر الخدمة فعلًا، مع `Retry-After` عند ملاءمته، وربط معرّف تتبع حقيقي بدل المرجع التوضيحي.
