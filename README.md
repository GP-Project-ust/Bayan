# بيان — BAYAN

### المساعد المؤسسي الذكي للجامعات العربية

اسأل عن بيانات جامعتك بالعربية — يحوّل سؤالك إلى SQL آمن، يسترجع السياسات واللوائح، يحلل ويرسم، ويجيبك في ثوانٍ.

**مساعد ذكاء اصطناعي مؤسسي يعتمد معمارية وكلاء متعددين (LangGraph) فوق نظام ERP جامعي حقيقي (Odoo + OpenEduCat)**

## نظرة عامة

**بيان** هو مشروع تخرج يبني مساعداً ذكياً مؤسسياً يُمكّن المستخدمين من التحدث بالعربية مع بيانات جامعتهم:

- **NL2SQL عربي**: تحويل الأسئلة العربية إلى استعلامات SQL آمنة تُنفَّذ للقراءة فقط فوق طبقة **Smart Views** مبسّطة
- **RAG**: استرجاع الإجابات من لوائح الجامعة وسياساتها وأنظمتها المعرفة
- **وكلاء متعددون**: Supervisor يوجّه السؤال بين وكلاء SQL / RAG / المحلل / المُعدّ — عبر LangGraph
- **إجابات غنية**: نص عربي + جداول نتائج + رسوم بيانية + تقارير قابلة للتصدير

المرجع الأساسي للمشروع هي **وثيقة مشروع التخرج** (مستودع Bayan-Documentation).

## هيكل المستودع

```
Bayan/
├── backend/            # FastAPI + وكلاء LangGraph + LLM Provider
│   └── app/
│       ├── agents/     # الوكلاء الخمسة: supervisor, sql, rag, analyst, reporter
│       ├── api/        # نقاط النهاية REST (v1)
│       ├── core/       # الإعدادات والسجلات
│       ├── db/         # اتصالات قواعد البيانات
│       ├── llm/        # مزوّد النموذج (Ollama Qwen 2.5 — قابل للتبديل)
│       └── schemas/    # مخططات Pydantic
├── frontend/           # Next.js — واجهة محادثة عربية RTL
├── database/
│   └── smart_views/    # طبقة المشاهد المبسطة فوق مخطط Odoo (ابتكار المشروع)
├── evaluation/         # مجموعة Golden Dataset + عدّادات القياس (هدف دقة 90%)
├── docs/               # التوثيق الهندسي (المعمارية، الوكلاء، Smart Views، الخطة)
├── scripts/            # سكربتات الإعداد والفحص
├── infra/              # تهيئة النشر (لاحقاً: Nginx + مراقبة)
└── .github/workflows/  # CI: فحص الكود + الاختبارات عند كل PR
```

## البدء السريع

### المتطلبات
- Docker + Docker Compose
- Python 3.11+ (للتطوير المحلي للـ backend)
- Node.js 20+ (للتطوير المحلي للـ frontend)

### التشغيل

```bash
git clone https://github.com/GP-Project-ust/Bayan.git
cd Bayan
cp .env.example .env        # عدّل القيم إن أردت

# البنية التحتية فقط (قواعد بيانات + كاش):
make infra

# أو المكدس كاملاً (يحتاج بناء الصور أول مرة):
make up
```

| الخدمة | العنوان |
|--------|---------|
| واجهة المحادثة | http://localhost:3000 |
| واجهة API (توثيق تفاعلي) | http://localhost:8000/docs |
| فحص الصحة | http://localhost:8000/api/v1/health |

### بيئة الاختبار (قاعدة بيانات الجامعة)

انظر `database/README.md` لطريقة ربطها ببيان بصلاحية قراءة فقط.
